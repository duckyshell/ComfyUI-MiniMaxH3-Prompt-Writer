# MiniMax guide bundle

The two English prompt-writing guides are vendored verbatim from the official
`MiniMaxAI/MiniMax-H3` Hugging Face repository at revision
`bfc8ed0353f5a9733be73e6b2c98ec0948195b86`.

- `VIDEO_PROMPT_WRITING_GUIDE_base_en.md`: T2VA, I2VA, FL2VA, and L2VA
- `VIDEO_PROMPT_WRITING_GUIDE_ref_en.md`: Reference mode

`backend/guides.py` records the canonical source URLs and source SHA-256 values,
normalizes only trailing line endings, and verifies content before use.

Do not silently treat community prompting recipes as official guide content.
